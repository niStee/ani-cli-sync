# Security Policy

## Reporting a Vulnerability

If you discover a security issue or vulnerability in this repository:

1. **Do not open a public issue.**
2. Email: 52573120+niStee@users.noreply.github.com
3. Describe what is affected, steps to reproduce, and the potential impact.
4. Allow up to 72 hours for an initial response before escalating.

## Supported Versions

Only the latest release / `main` branch is actively supported with security updates.
